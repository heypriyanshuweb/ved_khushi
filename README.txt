VED & KHUSHI WEDDING INVITATION WEBSITE

FILES
- index.html : website content
- style.css  : visual design and mobile responsiveness
- script.js  : countdown, animations, music control, sharing

HOW TO OPEN
Keep index.html, style.css and script.js in the same folder. Double-click index.html to preview in a browser.

MUSIC
Add a licensed MP3 file to this folder and name it wedding-music.mp3. Music is started by tapping the music button because browsers normally block autoplay.

YOUR WATERMARK PHONE NUMBER
In index.html, find:
<a href="tel:YOUR_PHONE_NUMBER">Add your phone number</a>
Replace YOUR_PHONE_NUMBER in the tel link and the visible text with your own number.
